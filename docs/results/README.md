## 파일 형식

- JSON: 실행 설정, 요청별 시작/완료 시각, 응답시간, 상태 및 오류 분류를 포함한다.
- CSV: 실행별 집계와 간격·행렬 간 비교에 필요한 요약값을 포함한다.

이 결과는 `C=1` 순차 실행에서 완료 후 추가 대기시간을 비교한 v1 실험이다.

동시성, 최소 요청 시작 간격, 시간 창 제한 및 다중 사용자를 포함한 새 계획은 `docs/transit-request-interval-experiment-plan.md`를 따른다. 이전 결과는 `C=1`, 완료 후 추가 대기 `0ms`가 동작했다는 근거로만 사용하며 최종 스케줄링 값을 결정하는 근거로 단독 사용하지 않는다.

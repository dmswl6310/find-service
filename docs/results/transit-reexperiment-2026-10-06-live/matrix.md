# ODsay 실제 실험 결과 — 일일 한도 소진으로 중단

2026-10-06 KST. 직접 ODsay fetch 시작과 JSON 수신 완료를 측정했다. 운영 브라우저/서버 큐를 거치지 않았다. C 상한 비활성화, G=0, 별도 R 제한 없음, 날짜/시간 미지정. 정상 결과 30건, 요청 시도 31건, 일일 한도 오류 1건. 복구 확인 요청은 사용자 화면 확인 후 취소했으며 추가 발송하지 않았다.

## 해석

- 250ms 두 배치에서 18/18 성공했고, 평균 배치 완료 시간은 2.116초였다. 500ms의 유일한 완성 배치는 4.179초였다. 반복 조건과 순서가 균형을 이루지 못해 최종 성능 차이로 확정하지 않는다.
- 마지막 500ms 배치는 4건만 발송하고 5건은 보내지 않았다. 완료 시간 1.564초는 성공한 9건 계산의 성능 지표로 사용할 수 없다.
- 마지막 응답은 HTTP 200, JSON error.code=429였다. 스크립트 초기 분류는 일반 odsay-error였지만 원본 오류 코드는 보존됐고 모든 비정상 응답에서 중단하도록 구현되어 즉시 새 호출은 멈췄다. 이 요약에서는 본문 429로 재분류한다. 원본 JSON은 수정하지 않았다.
- 콘솔의 30/30과 정상 응답 30회 후 오류라는 기록은 일일 한도 소진과 일치한다. 500ms가 위험하거나 250ms가 안전하다는 근거로 사용하지 않는다.
- 125ms 이하, 후보별 공정 반복, 5x5 및 다중 사용자 실제 실험은 미실행이다. 최적값 미확정, 운영 C3/S500 유지.
- 샌드박스 network-error 1건은 EACCES 연결 실패로 성능 집계에서 제외한다. 별도 원본 디렉터리에 보존했다.

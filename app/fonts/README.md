# Pretendard 글꼴 출처

`PretendardVariable.woff2`는 애플리케이션 UI에서 사용하는 기존 가변 웹폰트다. 이 파일은 이번 작업에서 변경하지 않았다.

`Pretendard-Regular.otf`는 Next.js 16 `ImageResponse`가 WOFF2를 지원하지 않기 때문에 Open Graph와 Twitter 이미지의 한글 렌더링에만 사용한다. 클라이언트 글꼴 구성에서는 이 OTF를 로드하지 않는다.
